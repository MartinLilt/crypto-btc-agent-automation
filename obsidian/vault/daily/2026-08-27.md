# 2026-08-27

## Съехали с Railway на свою коробку

**Итог дня: бот больше не на Railway.** Компьют, база и планировщик — на одной
машине, которую мы контролируем. €7.25/мес с НДС против $20.

### Коробка

`grid-stream`, **cx23** (2 vCPU x86 / 4 ГБ / 40 ГБ / 20 ТБ трафика), Нюрнберг,
**46.225.162.161**, Ubuntu 24.04. Доступ — `ssh root@46.225.162.161 -i ~/.ssh/binance_egress`.

- ufw: открыт только 22, unattended-upgrades включены
- Postgres 18 (как на Railway), база `grid`, UTF8
- `grid-stream.timer` — цикл раз в 4 часа вместо крона Railway
- `pg-backup.timer` — ночной `pg_dump` в 03:17 UTC, хранит 14 копий
- конфиг: `/etc/grid-stream.env` (root:bot, 0640), 30 переменных
- код: `/opt/grid-stream`, обновляется `git pull`

### Что оказалось неправдой

**Поле `available` в API Hetzner врёт.** CAX11 числился доступным во всех трёх
локациях EU — и в консоли, и в API отказывался создаваться
(`unsupported location for server type`). CX23, который оба публичных трекера
считали распроданным, создался с первой попытки. Оба трекера читают ровно то же
лживое поле. **Честная проверка наличия — только попытка создать сервер.**

**Консоль Hetzner игнорирует программные клики** — три клика вхолостую. Всё
делалось через API-токен.

### Чего не увидел сухой прогон

Тестовый цикл в paper-режиме прошёл идеально — и всё равно спрятал главное:
**ключ Binance привязан к IP**, и с нового адреса подписанные запросы отбивались
с `-2015`. Рыночные данные не подписываются, поэтому все ранние проверки
проходили. Лечится добавлением адреса в whitelist; сделано.

Мораль на будущее: **paper-прогон не проверяет права ключа.** Единственная
честная проверка после переезда — подписанный запрос с нового адреса.

### Сверка состояния

Балансы на бирже сошлись с перевезённым портфелем по монетам, а не по счётчику
строк: USDC 5.31801132 = касса до последнего знака, BTC 0.00036 = hold 0.00029 +
мешок 0.00007, ETH 0.00989667 = hold 0.0036 + два мешка по 0.0031,
SOL 0.306 = hold 0.242 + мешок 0.064.
