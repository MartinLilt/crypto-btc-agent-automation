# 2026-08-28

## Сутки рядом с нами работал второй живой бот

**Итог дня: в Telegram писали двое.** Наша коробка — ровно по расписанию, и копия
на Railway, которую все считали удалённой. Она же и приносила баны Binance.

### Симптомы, с которых начали

- сообщения приходят вразнобой, а не парой раз в 4 часа
- «опять бан от Binance», хотя переезд на свой IP был именно ради этого

### Коробка была чистой по всем меркам

Семь циклов подряд без сбоев (27.08 16:01, 20:02, дальше 00:01/04:01/08:01/12:01/16:02
UTC), вес **49 из 6000** за цикл, живая проба `x-mbx-used-weight-1m: 1`, ни одного
418/429/-1003/-2015 за неделю журнала. Ни крона, ни launchd, ни процесса на Mac;
вебхука у бота нет; получатели без дублей — 2 сообщения на цикл, как задумано.

### Развязка — в самом чате

В ленте перемешаны два отправителя: наши ровные пары (03:01, 07:00, 11:01, 15:01,
19:02 по местному) и одиночные «пустые» отчёты в 19:19, 00:45, 04:26, 12:56, 15:05
с неизменным `5 USDC · 0 закупок · 0 холдов`. Логи Railway закрыли вопрос:

```
⛔ HTTP 418: IP banned for another 113 min
⏸ waiting 113 min for it to lift (180 min of patience left)
storage: json+LIVE [slot 1]        ← Postgres не резолвится, ушёл в JSON
cash 5.32 · open bags 0 · holds 0
IP weight: 5716/6000 ‼️ foreign traffic on this shared egress IP
```

**Отсюда «хаос»:** крон срабатывал в 04:00/08:02/12:01/16:03 UTC как часы, но каждый
запуск досиживал чужой бан и писал в 09:56, 12:05, 16:11 — вразнобой поверх наших пар.

### Два механизма, которые это устроили

**Удаление проекта в Railway — это отложенный снос, а не действие.** API отдавал
`deletedAt: 2026-08-29T14:41Z`: из панели проект пропал 27.08, контейнеры работали
ещё сутки. При этом `railway status`/`link` отвечают «project is deleted» и
линковаться отказываются — то есть CLI его уже не остановит. Проверять удаление надо
через `railway list --json` и поле `deletedAt`, а не по отсутствию в панели.

**Пуш в `main` воскрешает убитый крон.** `railway down` погасил сервис 27.08 в 12:05
UTC, а пуш коммита `c775e9a` в 16:03 UTC поднял его обратно вместе с расписанием —
крон лежит в `railway.json` в репозитории.

### Насколько близко было

Копия работала в LIVE с рабочими ключами на whitelist-адресе, читала реальный
баланс, но состояние считала пустым. Не купила ничего только потому, что мешок
стоит 6.00 USDC, а свободных было 5.32. Пришли бы деньги (например, исполнись
ручной ордер на 34 LTC) — покупала бы вслепую, мимо настоящего состояния.
